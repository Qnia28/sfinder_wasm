# Secondary 분류 후보 C3

상태: **개발 후보 통합 검증 완료, 독립 QB 검증에서 반복 성능 회귀 확인, 제품 승격 보류**.
이 문서는 기존100K/60초 운영 정책을 최적 기준으로 확정하는 문서가 아니다.

## 분류 조건

| 관측 | 동작 |
|---|---|
| trivial exact 가능 | 즉시 반환 |
| 그 외 | integrated100K |
| integrated100K에서DFS진행추정치p100≥0.5, p100−p50≥(1−p100)/2 | 같은 탐색을 최대200K까지 연장 |
| integrated미완료 | threshold를 중단 없이 진행 |
| threshold50K미완료·CP변수≤4096 | CP1-worker 합류 |
| 큰CP모델·threshold100K미완료·증명단계50%미만 | CP 합류 |
| 나머지 | threshold 유지 |

CP 합류는 Rust를 포기하는 전환이 아니다. 최소K/원본중복행가중품질/stable-ID 증명을
모두 만족하는 결과만 완료로 취급한다. 증명prefix는 동일요청의 소유된 사본만 재사용한다.
보드ID·saved piece·명령이름은 분류 입력으로 사용하지 않는다.

## 입력 분석·worker 준비 비용

- integrated50K에 도달했을 때만 후속Rust worker를 준비한다.
- CP모델크기는threshold50K 관측까지 계산하지 않는다.
- 미사용worker와실패한CP는회수한다. CP시작실패 시Rust는계속한다.
- DFS진행추정치는예산선택용휴리스틱이며exact가지치기나수학적완료상한이아니다.

## 검증과 남은 범위

F1관측100jobs,독립예산비교52jobs,L1독립비용비교40jobs,통합28jobs를수행했다.
통합7입력두반복은28/28exact/reference일치,191파일해시와worker회수검증을통과했다.

- ELEPHANT J: C2 459/467ms → C3 182/172ms.
- ELEPHANT O:235/245ms →100/98ms.
- ALT SHOES L:361/362ms →199/206ms.
- 빠른pcinfo018 L:246/236ms →190/198ms.
- CP합류J/Z의이득과threshold회귀가드pcinfo030 I의경로를유지했다.

통합과독립실험의측정범위를구분한다. 모든C2난제를C3로다시측정한것은아니다.
독립반전그룹 검증에서큰지연반례가확인돼최종분류기본정책으로승격하지않는다.
기존개발입력에서조건을더맞추기위한cutoff미세탐색은하지않는다.

상세및두관측변동: [C3 결과](../../tools/validation/secondary-combined-policy-20260927/RESULT_KO.md).

## 독립 QB 검증 후속

새8반전그룹의13비자명행렬+기존3대조군을4조건×2회=128jobs로비교했다.
213해시/110완료witness/12진행관측감사통과. 새입력C3는24/26EXACT이며,
미완료2회는모든엔진미완료인같은입력이다. 정확성과별개로성능회귀가재현됐다.

- QB235 독립 `*p3,*p4` Z: CP3.120/2.581초, C3 7.873/7.047초.
  평균2.62배·4.61초지연,관측범위최대3.05배. 사전회귀기준두반복충족.
- threshold완료11,468상태로50K체크포인트에못미쳐CP가합류하지않았다.
  CP모델은2,729변수였다. 상태수기반합류기회가wall-time비용을놓치는반례다.
- 새입력F1선택/CP합류승리는없었다. 기존대조군의해당경로는유지됐다.

조건은위표그대로보존한다. 새cutoff를이자료에맞춰승격하지않으며다음설계는
상태당비용·경과시간관측을검토한후다른미사용그룹에서검증해야한다.
[독립 검증 결론과원자료](../../tools/validation/secondary-c3-newboards-20260927/RESULT_KO.md).

## CP worker 수 후속 비교

사용자질문에따라CP단독7입력과C3동시Rust4입력에서1/2worker를각2회비교했다.
44jobs/221해시/36완료witness감사통과. 완료단독6입력모두평균CP1우세였고,
CP2/CP1은1.009~1.736배. ordinaryJAWSI는실질적으로비슷했고반복2는CP2가
0.122초빨랐다. C3에서CP가이긴JAWSJ/Z는CP2가평균6.1%/10.6%느렸다.
따라서현재CP1조건을유지한다. primaryCP2선택을secondary에그대로전용하지않는다.

QB2358회기전진단은동일11,468상태/해답이며관측OFF의기존WASM도약5초였다.
50K상태이전의비싼탐색을wall-time관측으로다루는문제가남아있다.
[worker비교·기전진단결론](../../tools/validation/secondary-cp-workers-20260927/RESULT_KO.md).
