# A_H9 + 지속 exact 탐색 / r8 대규모 단일검증

사용자 승인: Opus 통합개선안을 수정·테스트하고, 어려운 문제도 T/CP 중 하나가 계속 탐색하도록 한다. CP120초는 과거 테스트용 제한이며 제품 종료조건이 아니다. 새 테스트 호출한도는10분. 결과는 원격에서 모음 ZIP으로 제공한다.

## 제품 변경

- 기본 Auto의 bounded probe를 A_H9로 변경: non-hard d≤16, hard d≤9에서 I100K. 그 밖은 T부터 시작. 구조미상은 기존baseline 판정, 기존trivial/decomposition 계약 유지.
- 제품 CP 내부한도는 `null`(무제한). CP는 secondary 경과60초에 합류하며 T의 진행을 버리지 않는다. CP가 실패/미완료여도 T는 계속 탐색한다.
- T worker 오류 시 살아 있는CP를 유지하거나 즉시시작한다. 양엔진이 모두오류/미완료 종료하면 명시적오류를 반환하며 무응답으로 남기지 않는다. 사용자취소와정상exact승자 시 모든자손을회수한다.
- explicit CP도 내부한도 없이 quality와stable-ID tie의완전증명을 기다린다. FEASIBLE을exact로반환하지않는다.
- 메모리부족/외부종료/양엔진실패까지 결과를 보장하는 것은 아니다. 시간만 오래걸린다는이유로제품탐색을중단하지않는다.
