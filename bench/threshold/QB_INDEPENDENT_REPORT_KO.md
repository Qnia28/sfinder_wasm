# Cycle7 QB 독립 데이터 100개 검증

## 결론

**100개 생성·3쌍 측정·특이 입력7개의10쌍 재확인·독립 감사까지 완료. 그러나 QB에서 mask20의 뚜렷한 성능 우위는 확인되지 않았다.**

- 기본1,200회+재확인280회=1,480회 전부 EXACT. 생성 실패/solver TIMEOUT/미실행/완료차이/메모리 경보 없음.
- 기하평균 speedup은0→20 **1.016561배**,16→20 **1.006539배**. 특히rootForced 증분 비교는49빠름/51느림이며,97입력이≥10%range-noisy이고71입력의방향이쌍간변동함. 작은점추정치를보편적개선으로해석하지않음.
- 최초8개비교의material경보는10쌍에서재현되지않았지만,16→20의row007/O·035/L·072/T는각8/10쌍느리고paired＋2.63/2.87/3.11ms. **5ms material기준미달이지회귀가없다는뜻은아님.**
- `currentPropagation`의기존cycle1 A근거와`rootForced`의**cycle1에한정된conditional A**를유지. QB만으로rootForced를범용A로올리거나mask20을제품기본값으로채택할근거는부족함. mask20은mask16과함께제품경로검증후보로남기되,이번작업에서제품통합은하지않음.
- 전체Actions10.13분,실제shard job동시최대10. 기본측정step창2.82분,재확인step창12초. 최대관측nativeMs는101.77ms였음. 긴/어려운QB입력의효과까지검증한결과가아님.
- 원본100개physical setup은87mirror그룹,**99개서로다른행렬core**. `c7-2plus2-qb-row-175-L`와`c7-2plus2-qb-row-018-L`의keys/rows/K/seed가동일함. 무작위선정100개를그대로유지했으며중복을교체하거나100독립행렬이라고주장하지않음.
